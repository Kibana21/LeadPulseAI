## 🔧 Technical Notes

### Voice Synthesis (Web Speech API)
Works in:
- ✅ Chrome/Edge (excellent)
- ✅ Safari (good)
- ⚠️ Firefox (limited)

Fallback: Pre-record audio files

### Performance
- Target: < 2 second page load
- Animations: 60fps (use CSS transforms, not top/left)
- Images: Use SVG avatars (faster than photos)
- Charts: Chart.js is lightweight (~65KB)

### Browser Compatibility
Primary: Chrome (most executives use this)
Secondary: Safari (MacBook users)
Test but not critical: Firefox, Edge
